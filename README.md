# Calculadora 2026



## Visão Geral
Aplicação de console desenvolvida para prover operações aritméticas fundamentais, oferecendo uma interface intuitiva com suporte a histórico de cálculos e geração de tabuadas.

## Funcionalidades Principais
*   **Operações Aritméticas**: Processamento de soma, subtração, multiplicação e divisão.
*   **Consistência de Dados**: Validação nativa para evitar erros de divisão por zero.
*   **Recursos Adicionais**: Módulo para geração de tabuada e armazenamento de histórico de operações.

## Instruções de Uso
1.  Obtenha o código via clone de repositório ou download do arquivo `.zip`.
2.  Acesse o diretório raiz através do terminal.
3.  Execute a restauração dos pacotes do projeto:
    ```bash
    dotnet restore
    ```
4.  Inicie a aplicação:
    ```bash
    dotnet run --project Calculadora.ConsoleApp
    ```

## Requisitos de Sistema
*   **.NET SDK 10.0** ou superior.
